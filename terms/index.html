Terms

These terms cover the personal Chelete backup utility described on this site. They do not create a public service, a customer account, or access to the Chelete application.

Personal use

The utility is for the operator’s own use. It is not shared as a product for the public, and it is not meant for more people than Google’s personal-use limit allows.

What the operator accepts

The operator keeps the encryption key outside Google Drive and outside this website. The operator decides when a scheduled copy is turned on, and the operator deletes encrypted files that should not remain in Drive.

The utility does not promise that a copy can be restored if the separate key is lost, or if the encrypted file has been deleted.

These pages

This website only explains the utility. It does not store backups, does not accept uploads, and does not provide a login.
