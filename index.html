Chelete backups

This site describes a personal backup utility. It is not the Chelete application, and it has no login.

The utility encrypts a backup on the operator’s computer. It then uploads only that encrypted file to a Google Drive folder created by this app.

Google Drive access

The app requests one Google permission, drive.file. With that permission the app can create files and can see, change, and delete files this app created. It does not request access to the rest of Google Drive.

Choosing a folder tells the utility where to put its own files. That choice is not a separate restriction inside the Google permission. The permission itself is limited to files this app creates.

Encryption

Each backup is encrypted before it is uploaded. Google Drive stores the encrypted file. The encryption key is not uploaded and is not stored on this website.
