Privacy

This page describes the personal Chelete backup utility. These pages do not collect messages, and they do not set cookies.

Who can use it

The utility is for one operator. It is not offered as an account other people can sign in to.

Drive access

The only Google user data the utility requests is through drive.file. That permission lets the app create files and lets it see, change, and delete files this app created. It does not grant the app the rest of the operator’s Drive.

The file placed in Drive is an encrypted archive. The utility does not put the encryption key in Drive.

Encryption and key separation

Encryption happens on the operator’s computer before upload. The key is kept apart from the Drive folder and apart from this website. Someone with the Drive file still needs that separate key to read the backup.

Retention

The utility is built so that a later activated schedule would keep 14 daily copies, and then 4 weekly and 3 monthly archives of those daily copies. That schedule is not running.

An uploaded encrypted file stays in the folder this app created until the operator deletes it. The program does not currently remove older Drive copies by itself.

Deletion

The operator can delete an encrypted file from the folder this app created. Removing the app’s Google permission stops the app from using Drive afterward. Files already stored there remain until they are deleted in Drive.

Deleting a Drive file does not delete the separate encryption key. Deleting the key does not delete the Drive file. Without the key, the archive cannot be decrypted.
